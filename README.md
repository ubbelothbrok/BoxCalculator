# Box Calculator

A C++ program to calculate the surface area and volume of a box.

## Build & Run (One-liner)

If you have CMake and a C++ compiler installed, you can build and run everything with this single command from the project root:

```bash
cmake -B build -S . && cmake --build build && ./build/box_calculator
```

## Manual Steps

1. **Configure:** `cmake -B build -S .`
2. **Build:** `cmake --build build`
3. **Run:** `./build/box_calculator`
