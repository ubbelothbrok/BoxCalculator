# Object Calculator

## Build & Run 2D Object Calculator
Navigate to the root directory and run:
```bash
g++ src_for_2d_object/Object2D.cpp src_for_2d_object/main.cpp -o calc_2d && ./calc_2d
```

## Build & Run 3D Object Calculator
Navigate to the root directory and run:
```bash
g++ src_for_3d_object/Object3D.cpp src_for_3d_object/main.cpp -o calc_3d && ./calc_3d
```
